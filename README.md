# Impossible Snake 3D

9 arenas & rulesets, live target ghost race, daily UTC board, and 4-Color Battle. Fill the board 100%.

Play live: https://khaledsabae.github.io/impossible-snake/

- **3D / 2D Toggle**: WebGL2 3D board with instant 2D fallback
- **Ghost Race**: Race the 100% target run or your own personal best
- **Stages 1–9**: Classic, Infinite Wrap, Golden +3, Four Pillars, Moving Hazards, Donut Ring, Hourglass Maze, Skull Arena, Twin Chambers
- **Controls**: Arrow keys / WASD on desktop, swipe or on-screen keycaps on mobile
